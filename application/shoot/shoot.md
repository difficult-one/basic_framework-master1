# shoot



## 工作流程

初始化3个电机，包括发射的2个 M3508 和拨盘的 M2006。当前步兵联调版本不初始化
弹舱盖舵机。M2006 初始化后保持零力矩，收到有效控制命令时再进入速度环或位置环。
应用订阅 `shoot_cmd` 话题并发布 `shoot_feed` 话题。

1. 从shoot_cmd获取消息
2. 根据工作模式确定是否急停
3. 根据弹速档位设置摩擦轮空载联调目标，并检查两侧实际速度
4. 两侧摩擦轮进入容差范围并稳定 300 ms 后，将 `friction_ready` 置位
5. 任一发射电机尚未收到反馈或离线时，三个发射电机全部保持零力矩
6. 摩擦轮未就绪时强制拨弹目标为停止
7. 单发和三发只响应模式上升沿；请求可等待摩擦轮就绪，但松开后会取消，且一次请求只消费一次
8. M2006 单发角度和连发速度均由 36:1 减速比及每圈弹数换算
9. 设定反馈数据并推送到 `shoot_feed` 话题

`FRICTION_SPEED_15_APS`、`FRICTION_SPEED_18_APS` 和
`FRICTION_SPEED_30_APS` 当前只是无弹空载联调值，不代表真实 15/18/30 m/s 弹速。
必须通过测速仪或裁判系统重新标定后才能进行实弹测试。
